# Security

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

Use GitHub's private vulnerability reporting feature for this repository when it is available. If
it is not available, contact the repository maintainers through GitHub to request a private reporting
channel before sharing sensitive details.

Please include enough information to reproduce the issue, its potential impact, and any suggested
mitigation. Do not include credentials, personal data, or other secrets in a report.
